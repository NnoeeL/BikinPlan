Master Prompt — Langsung Jadi dalam Sekali Kirim

Kamu tidak perlu pusing memikirkan kapan harus kirim AGENTS.md atau memecah file. Master Prompt ini sudah merangkum seluruh spesifikasi PRD, arsitektur, dan protokol pengerjaan otomatis. Cukup buka AI Coding Agent kamu (Claude Code, Hermes Agent, Antigravity, Cursor, atau ChatGPT) di folder proyek kosong, lalu paste prompt ini — agent langsung paham dan langsung bikinin!

🗺️

Arahan Pengerjaan Proyek: Langkah Awal Sampai Selesai

1 Langkah Awal

Bikin folder proyek baru di komputermu (misal mkdir my-app && cd my-app) dan buka AI Agent di terminal folder itu.

2 Kirim Prompt

Paste Master Prompt di atas ke AI Agent. Agent langsung memproses dan mulai membangun Fase 1 (Layout & Mockup UI).

3 Cek di Browser

Begitu Fase 1 beres, jalankan npm run dev. Buka browser, klik-klik tampilannya dulu. Pastikan kamu suka desainnya!

4 Lanjut Backend

Jika UI sudah cocok, ketik di chat agent: "Tampilan oke, lanjut ke database & API". Agent akan menyusun tabel & endpoints.

5 Langkah Akhir

Agent menjalankan audit build production tanpa error. Proyekmu beres 100% dan siap di-deploy ke hosting!

            1
            Langkah Paling Awal: Setup Folder Proyek
          

          
Sebelum membuka AI Agent apa pun, buat folder kosong baru di komputermu:

          
mkdir my-app && cd my-app

          
Setelah men-generate dokumen di NgodingYuk, klik tombol "Download PRD + Tasks (.md)", lalu pindahkan 3 file tersebut ke dalam folder my-app/:

          
    
            
  • PRD.md — Spesifikasi lengkap arsitektur, DDL database, dan kontrak API.
    • 
            
  • TASKS.md — Daftar 24 micro-tasks berfase yang memandu pengerjaan harian.
    • 
            
  • AGENTS.md — Instruksi dan aturan main agar agent tidak membuat kode berantakan (*anti-slop*).
    • 
          

        


        
        

          

            2
            Kapan Mengirim File PRD dan AGENTS.md? (First Handshake)
          

          
Kirim file ini DI PERCAKAPAN PERTAMA KALI, tepat saat kamu baru membuka Claude Code, Hermes Agent, Antigravity, atau Cursor di terminal folder tersebut.

          
PENTING: Jangan langsung menyuruh agent coding atau membuat database! Berikan prompt inisialisasi pembuka berikut:

          
          

            
Baca PRD.md dan AGENTS.md di folder ini sebagai acuan arsitektur dan batasan pengerjaan.
Pahami alur 4 fase (Fase 1 Frontend Mockup -> Fase 2 State -> Fase 3 Database & API -> Fase 4 Integrasi).
DILARANG membuat tabel database, API rumit, atau menulis kode fitur sebelum saya memberikan nomor task spesifik.
Apakah kamu sudah membaca dan paham arsitekturnya?

            
          

          
Tujuan handshake ini: Membangun mental model arsitektur di memori agent terlebih dahulu agar agent tidak berhalusinasi atau melompati tahapan.

        


        
        

          

            3
            Siklus Eksekusi Task (Satu Task per Giliran)
          

          
Setelah agent menjawab "Paham", buka tab "Roadmap & 24 Tasks Board" di NgodingYuk:

          
    
            
  • Mulai dari task pertama yang belum selesai (misalnya T-01: Setup Repo & Layout Shell).
    • 
            
  • Klik tombol "Copy Prompt Agent" pada task tersebut.
    • 
            
  • Tempelkan ke terminal agent. Agent akan fokus menyelesaikan HANYA checklist pada task tersebut.
    • 
            
  • Agent akan menjalankan kriteria verifikasi penerimaan (*acceptance test*) sebelum melapor selesai.
    • 
          

        


        
        

          

            4
            Checkpoint Verifikasi Manusia (Jangan Biarkan Agent Nyelonong!)
          

          
Sesuai formula Frontend Mock First, Fase 1 (T-01 s/d T-06) sengaja menggunakan data tiruan statis:

          
    
            
  • Setelah Fase 1 selesai, nyalakan server lokal (npm run dev) dan buka browser.
    • 
            
  • Klik-klik tombol, navigasi, dan filter tampilan di browser. Pastikan tampilannya sudah sesuai keinginanmu.
    • 
            
  • Jika tampilan sudah disetujui, barulah perintahkan agent untuk lanjut ke Fase 2 (state) dan Fase 3 (skema database).
    • 
            
  • Manfaat: Kamu tidak membuang token untuk backend yang salah arah, dan tampilan UI sudah terbukti bagus sejak hari pertama!
    • 
          

        


        
        

          

            5
            Panduan Khusus per Aplikasi / Platform AI Agent
          

          
Pilih aplikasi AI Agent yang sedang kamu gunakan untuk melihat panduan langkah demi langkah yang disesuaikan:

          
          

            
            
            
            
          


          
          

            

              🚀 Hermes Agent (Desktop App & CLI)
              Full Auto-Pilot
            

            
    
              
  1. Buka Hermes Desktop App: Kamu bisa langsung menggunakan chat Hermes yang sedang aktif ini.
    2. 
              
  2. Salin & Paste Master Prompt: Klik tombol "Salin Master Prompt" di NgodingYuk, lalu paste ke chatbox Hermes.
    3. 
              
  3. Hermes Bekerja Otomatis: Karena Hermes memiliki built-in autonomous tools (write_file, terminal, browser_exec, execute_code), Hermes akan langsung membuat folder, menulis seluruh file kode, menginstall dependensi, dan menyalakan dev server tanpa kamu perlu buka terminal terpisah!
    4. 
              
  4. Lihat Preview Langsung: Kamu bisa melihat hasil UI aplikasimu langsung di panel preview Hermes Desktop di samping chat.
    5. 
            

          


          
          

            
🟣 Claude Code CLI (Anthropic)

            
    
              
  1. Siapkan Folder Proyek: Buka terminal di komputermu, buat folder baru, lalu masuk: mkdir my-app && cd my-app.
    2. 
              
  2. Nyalakan Claude Code: Ketik perintah claude di terminal.
    3. 
              
  3. Paste Master Prompt: Tempelkan Master Prompt dari NgodingYuk pada percakapan pertama.
    4. 
              
  4. Biarkan Claude Bekerja: Claude Code akan membuat repository, setup Tailwind CSS, dan menyusun mockup UI Fase 1 secara terstruktur.
    5. 
              
  5. Verifikasi: Setelah Fase 1 selesai, buka browser (npm run dev). Jika sudah puas dengan UI-nya, ketik "Lanjut ke backend & database".
    6. 
            

          


          
          

            
⚡ Cursor / Antigravity IDE

            
    
              
  1. Buka Folder Proyek: Buat folder proyek baru dan buka folder tersebut di Cursor atau Antigravity.
    2. 
              
  2. Buka Composer / Agent Mode: Tekan Ctrl + I (Windows) atau Cmd + I (Mac).
    3. 
              
  3. Pastikan Mode "Agent" Aktif: Pilih mode Agent (bukan Chat biasa) agar AI memiliki izin membuat dan menyunting file di proyekmu.
    4. 
              
  4. Paste Master Prompt: Tempelkan Master Prompt dan tekan Enter. Klik "Accept All" untuk setiap file yang digenerate oleh AI.
    5. 
            

          


          
          

            
💬 ChatGPT / Claude.ai (Web Browser)

            
    
              
  1. Buka Editor Kode: Buka VS Code di folder proyek kosong.
    2. 
              
  2. Kirim Master Prompt: Buka ChatGPT atau Claude.ai, lalu paste Master Prompt.
    3. 
              
  3. Pengerjaan Interaktif: Minta AI memberikan isi kode file per file (dimulai dari package.json, layout, dan komponen UI mock).
    4. 
              
  4. Salin Berkas: Buat file di VS Code sesuai instruksi AI hingga Fase 1 selesai.
    5.
