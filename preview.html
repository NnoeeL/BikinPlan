🧭 Kapan & Bagaimana Kirim File ke AI Agent? (Klik di Sini)
[ + Lihat Panduan ]
1. Langkah Awal: Buat folder proyek (mkdir my-app && cd my-app), lalu taruh PRD.md, TASKS.md, dan AGENTS.md di folder tersebut.
2. Kapan Kirim ke Agent? Di percakapan pertama kali saat membuka Claude Code / Hermes / Cursor di terminal folder itu. Jangan langsung suruh coding! Kirim prompt handshake:
Baca PRD.md dan AGENTS.md di folder ini. Pahami arsitekturnya. DILARANG membuat kode sebelum saya berikan task pertama. Paham?
3. Eksekusi Satu-per-Satu: Buka TASKS.md, klik tombol Copy Prompt pada task T-01, paste ke agent. Selesaikan satu-satu.
4. Verifikasi di Browser: Setelah Fase 1 (UI Mockup) beres, buka browser dan tes klik tampilan dulu. Pastikan UI pas sebelum lanjut ke database!
